# Idées post-MVP

- Passerelle télécom réelle (intégration opérateur béninois pour SMS entrants/sortants)
- Langues locales traduites (fon, yoruba, dendi, bariba…)
- Prédictif par machine learning (remplacer les règles d'usure par des modèles entraînés sur l'historique réel)
- Application mobile native (Android) pour les zones sans navigateur moderne
- Multi-tenant national (une instance par pôle ou par commune, avec consolidation centrale)
- Intégration cadastre numérique (programme p. 23) quand disponible
- Intégration « Dites-le-nous une fois » (programme p. 55) pour éviter la double saisie identité agent
- Plateforme nationale de données (programme p. 64) — exports automatiques
- Module paiement (réglements des prestataires d'entretien via mobile money)
- Recueil de mesures réelles depuis capteurs IoT (intégration LoRaWAN ou 4G)
- Interface USSD pour signalement sans smartphone ni données mobiles
- Mode sombre et tailles de police réglables (accessibilité avancée)
- Application Electron pour usage sur ordinateur communal sans navigateur récent
